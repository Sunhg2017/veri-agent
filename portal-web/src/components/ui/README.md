# UI Component Stories

This directory contains the reusable portal UI primitives and their Storybook stories.

- `DataTable`: sortable, selectable, loading and empty table states.
- `SelectField`: labeled select with hint, error and disabled states.
- `TreeView`: hierarchical navigation with selected, expanded and disabled nodes.
- `State`: shared spinner, skeleton and empty-state blocks.
- `ConfirmDialog`: confirmation flow backed by the Radix dialog provider.

Run `npm run storybook` from `portal-web` for local review, or `npm run build-storybook` for CI validation.
