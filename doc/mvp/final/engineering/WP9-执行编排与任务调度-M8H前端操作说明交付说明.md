## 1. 目标与范围

M8H 目标是补齐 `WP9-8.4 前端操作说明`，把已经落地的 `#execution` 工作台能力整理成用户可执行的浏览器路径。交付后，用户无需 curl 即可按文档完成：

1. 进入 `执行编排` 并理解权限边界。
2. 新建、编辑、归档执行计划。
3. 配置多节点 DAG、执行 dryRun 并解释 issue。
4. 手动触发 run，查看运行详情、节点状态、traceId 和 errorCode。
5. 取消运行、重试失败运行、导出脱敏执行摘要。
6. 新增 WEBHOOK/CRON trigger，执行 dryRun、启停和查看事件证据。

本切片只补用户操作说明与交付记录，不改变前端 UI、API contract 或服务端调度语义。

## 4. 风险与后续

1. 文档说明基于当前 `ExecutionWorkbench` 能力；如果后续 UI 文案、按钮或权限发生变化，需要同步更新本说明和 Playwright smoke。
2. 本文记录的是 M8H 当时的阶段边界；按当前基线，WP10 完整报告消费已由后续里程碑承接交付，剩余后续专项聚焦真实供应商 OAuth/App 安装、独立 worker 管理页面和 CRON 生产容量看板。
3. 本说明不能替代服务端权限校验；前端按钮显隐只做体验优化，最终准入仍由后端权限、项目 scope、计划状态和全局开关控制。
