# WP1 单平台化调整说明

## 调整结论

WP1 不再建设多租户体系。平台边界调整为“单平台、多部门、多项目、多应用、多环境”，权限和数据隔离从租户边界下沉到部门、项目、应用、环境和角色授权范围。

## 影响范围

- 取消租户管理页面、租户生命周期、租户管理员、租户级配置和跨租户隔离验收项。
- 取消数据库 `base_tenant` 表和所有业务表 `tenant_id` 字段。
- 认证上下文不再返回 `tenant_id`，当前用户只保留用户、角色和账号状态信息。
- 预置角色将 `TenantAdmin` 调整为 `PlatformAdmin`。
- P0 权限点移除 `tenant:*`，权限范围保留 `PLATFORM/DEPARTMENT/PROJECT/APPLICATION/ENVIRONMENT/SERVICE`。
- 审计日志不再按租户过滤，按平台、部门、项目、应用、环境和资源对象过滤。

## 调整后的 WP1 P0 边界

1. 平台初始化：创建首个 `SuperAdmin`。
2. 身份认证：登录、当前用户、Bearer Token 基线。
3. 组织治理：部门、部门成员、部门负责人。
4. 权限治理：平台内置角色、角色权限、用户/部门角色绑定。
5. 项目治理：项目、项目成员、项目关联部门。
6. 应用与环境：应用登记、环境配置、变量和密钥引用。
7. 审计与安全：审计日志、敏感配置引用、密文存储、操作追踪。

## 后续文档处理

历史草稿中仍可能出现多租户描述，当前以本说明、最终迁移脚本和当前代码实现为准。后续 PRD 和架构设计正式版应以“单平台、多部门、多项目、多应用”作为唯一口径继续维护。
